Curso de Desarrollo con IA – MoureDev

Autor del curso: Brais Moure (MoureDev)

Objetivo general

Aprender a desarrollar aplicaciones utilizando inteligencia artificial, agentes de programación y sistemas multiagente.

Programa formativo
Día 1 – De la idea a la instrucción perfecta

Definición del proyecto, planificación y diseño de instrucciones para IA.

Día 2 – Programa con agentes bajo control

Desarrollo de funcionalidades mediante agentes supervisados.

Día 3 – Usa multiagentes para desarrollar mejor

Coordinación de múltiples agentes para desarrollar y mejorar la aplicación.

Herramientas
Cursor
Warp
Git
GitHub (cuando sea necesario)
Metodología de desarrollo

Utilizaremos Git Flow:

main: versiones estables.
develop: integración del desarrollo.
feature/*: nuevas funcionalidades.
release/*: preparación de versiones.
hotfix/*: correcciones urgentes.
Organización
00_DOCUMENTACION: documentación general.
01_DIA_1_IDEA_E_INSTRUCCIONES: contenidos del primer día.
02_DIA_2_AGENTES_BAJO_CONTROL: contenidos del segundo día.
03_DIA_3_MULTIAGENTES: contenidos del tercer día.
04_PROYECTOS_PERSONALES: proyectos propios.
05_EXPERIMENTOS: pruebas y experimentación.
Regla fundamental

La aplicación desarrollada durante los tres días será un único proyecto con un único repositorio Git.
